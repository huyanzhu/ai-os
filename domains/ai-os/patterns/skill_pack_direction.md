# 找方向技能包（基于 GTD 调研）

**解决**："我找不到方向，总要自己说现在做什么、等会做什么。"（= W10「我不想总靠自己想起下一步」的 Skill 侧解法）

**对应角色**：生产力/时间管理方法论（GTD，David Allen 2001——业界最被引用的个人生产力体系）。

**核心洞察（GTD 灵魂）**：**大脑是用来思考的，不是用来记忆"接下来做什么"的。** 找不到方向 = 大脑在硬扛外脑该做的事（未竟事项清单）。把所有未竟事项放到可信赖的外部系统，大脑释放后自然有余力想方向。

**研究证据**（调研所得）：定义了 Next Action（具体 where/when/how）的人，跟进执行的概率比只持模糊意图的人高 **2-3 倍**。

## 五步闭环（GTD 原文 + AI-OS 映射）

### ① 收集 Capture——清空大脑
- 把所有未竟事项/想法 100% 写出来（头脑扫描），不留在大脑
- **AI-OS 映射**：收工写回 MEMORY「下次开工建议 (W10 auto)」/ 观察文件 / 日志——AI-OS 就是你的外脑

### ② 理清 Clarify——定义下一个物理行动
- 每项问"Is it actionable?"：不可行动→归档/将来也许；可行动→**定义下一个物理行动**
- Next Action 标准：具体、可见、物理动作（"给 Jack 打电话"→"周五晚 8 点给 Jack 打电话问报告格式要求"）
- **两分钟原则**：<2 分钟立即做，不组织（组织成本 > 执行成本）
- **AI-OS 映射**：standup deriveNextStep（自动推导候选下一步）；卡住问"完成这件事的第一个物理动作是什么"

### ③ 组织 Organize——放进对的清单
- GTD 六清单：项目清单 / 下一步行动清单（按情境 @电脑/@电话/@外出）/ 日程表 / 等待清单 / 将来也许 / 参考
- **AI-OS 映射**：工程计划差距清单（项目）、PRODUCT_BACKLOG（项目）、workflows（流程路由）、CURRENT_GOAL（状态锚）

### ④ 回顾 Reflect——系统可信度的引擎（最重要）
- 每日回顾（5 分钟）：看日程+下一步清单，定今天 3 件事
- **每周回顾（30-60 分钟）**：清空收集箱、每个项目确认有下一步、更新清单——没有周回顾，清单过期，大脑重新焦虑
- **AI-OS 映射**：wrapup（收工白干检测）+ 收工五问（Reality Gap/Value/新知识）+ standup（状态刷新）

### ⑤ 执行 Engage——四判据选当下动作
- **情境 Context**（我现在在哪/有什么工具）→ **可用时间** → **可用精力** → **优先级**（以上条件下哪个最重要）
- **AI-OS 映射**：Q5 判据闸门（能否更接近活下来）+ 最小差距优先（工程轨道）

## 检查清单（找不到方向时自测）
- [ ] 我清空过收集箱吗（大脑里的未竟事项都写出来了吗）？
- [ ] 每个事项有「下一个物理行动」吗（不是模糊方向）？
- [ ] 我在用四判据选动作吗（情境/时间/精力/优先级）？
- [ ] 我定期回顾吗（每日+每周）？——没有回顾，系统会腐烂
