# Exemplar A16 — Working Memory（独立重塑）

**学到**：如何让 Capability 进入正常工作闭环，并跨轮消费。

## 路径

```text
现象：任务中建卡 0 触发（未进决策空间）
→ 排查：环境可达 / TASK.md 替代 / 入口文档（均排除）
→ 根因：[CONTROLLED] 条款跳过 Bootstrap（人为关闭入口）
→ Reshape：入口链 + list 标题摘要 + 归档门槛
→ 验证：obs3 建卡→维护→归档；stage4 跨轮消费
→ 项目级延伸：方案 B（项目文件夹 + PROJECT.md）从零自发形成（DevJournal）
```

**结果**：独立 V2 Capability。
