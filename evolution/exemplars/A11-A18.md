# Exemplar A11/A18 — Searchable（Delivery Reshape）

**学到**：如何把候选从"存在"推到"进入决策空间"。

## 路径

```text
现象：experience_push 触发但候选零消费（检索=仪式）
→ 根因：候选只是文件名，没进 Agent 注意空间
→ Reshape：候选 + 内容摘要 + "请采纳"（Task-driven 送达）
→ 验证：bootstrap-roots 被读/引用/影响行为（footprint 有值）
```

**结果**：Searchable 方向性支持；正确模型 = Task-driven retrieval（任务即检索条件，Agent 负责判断）。
