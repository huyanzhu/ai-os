# Corpus-Level Evolution（Exemplar · 2026-08-24）

> 意义：第一个**语料级** Evolution 案例——不是接一个 Skill，而是连续吸收一整套外部 Skill Corpus，并暴露环境自身缺口。

## 输入

- 11 个同源外部 Skill（deepseek-ai/deepseek-harness 的 DSH corpus）
- 唯一指令："请把这个 Skill 接入 AI-OS。"——每个 fresh Evolution agent 独立裁决，无批次/无预测提示

## 过程

11 次独立 Intake → Re-Mapping（9 份 Skill Profile）→ Work-Mode 试点物化（pre_push + prose）→ Corpus-Level Review

## 结果

- **Growth 分布**：2 Facet Fusion + 9 Knowledge（其中 2 个已物化为完整工作模式单位）
- **0 膨胀**：无新 Line / 新注册表 / 新 Taxonomy；全部进既有载体
- **Prediction vs Observed**：Human 方向 7/11、价值 6/11 分歧——Evolution 系统性发现 Human 判为"低价值/无载体"的 Skill 里有可迁移层
- **诚实**：9/9 真实消费 Q1–Q5 UNKNOWN（presence ≠ use ≠ influence）

## 教训（暴露的环境缺口）

1. **Knowledge Sink 偏置**：intake 默认"方法型 → 拆知识"，未先问"能否完整收纳 / 融合"（D-033/D-034）
2. **多关系对象**：Skill 不是单标签；物理承载 ≠ 语义身份（D-034）
3. **工具 cwd 污染**：v1 镜像误调会静默读 v1 树（Evidence contamination；P0，已隔离 D-036）
4. **语料型输入的"无既有工作面"判定成本高**（全库重读）——相关对象网已登记（D-038）
